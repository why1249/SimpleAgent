# Simple Agent Web 前端

## 设计风格与方向

核心定位：**TUI 交互模式 + 冷峻工业风现代浅色 GUI**。

后续迭代与样式修改请保持以下视觉与交互准则，避免退回通用网页聊天模板风格：

- **黑白灰高对比色板**：以浅灰白画布（`#f5f5f6`）、纯白控件表面（`#ffffff`）和深石墨黑（`#141416`）构成主视觉；不使用网页亮蓝等装饰性强调色，红/绿/琥珀色仅克制用于状态字符与错误提示。
- **锐利微圆角与细线结构**：全局采用 `2px ~ 4px` 微圆角与 `1px` 实线分割；常规区块零阴影，聚焦态直接切换 `1px` 深色实线边框，不使用胶囊标签（`999px`）、呼吸小圆点与发光外圈。
- **去盒子化的终端流排版**：
  - **启动空状态**：采用左对齐等宽规格面板展示真实会话环境（目录、模型、工具、命令速查），不放口号标题与预设提示词卡片。
  - **执行步骤流**：思考与工具调用不套独立卡片外框，采用左侧 `1px` 竖线串联的单行等宽树状日志（运行态盲文字符帧 `⠋⠙⠹⠸` + 完成态 `✓` 与耗时），点击按需展开 `args / output`。
  - **输入区**：底部保留居中限宽（默认 `780px`）的无阴影命令行输入框，支持 `/` 命令补全与 `↑/↓` 历史回溯。
- **字体严格分层**：界面骨架、状态读数、命令行、步骤流与表单统一使用等宽字体（`--font-mono`）；仅 Markdown 回复正文使用无衬线字体（`--font-sans`）保证长文阅读体验。

## 目录结构

```
src/simple_agent/web/
├── index.html                    # 页面结构骨架（顶栏 / 启动规格面板 / 对话流 / 居中输入行 / 配置弹窗）
├── styles/
│   ├── tokens.css                # 全局设计变量：工业风色板、字体栈、微圆角、版心宽度（改风格优先改这里）
│   ├── layout.css                # 页面框架布局（顶栏高度、滚动容器、居中限宽输入区、细窄滚动条）
│   ├── components.css            # 顶栏读数、启动面板、用户指令条、树状步骤流、Markdown、命令浮层与弹窗
│   └── highlight-light.css       # 适配浅色背景的代码块语法高亮
└── js/
    ├── state.js                  # 集中状态管理（App.state）
    ├── bridge.js                 # 与 Python AgentBridge 通信的唯一入口（收发事件）
    ├── main.js                   # 总入口：初始化各模块、分发后端事件、绑定全局快捷键
    ├── utils/
    │   ├── dom.js                # 轻量 DOM 封装、智能贴底滚动、共享终端字符帧动画与耗时格式化
    │   └── markdown.js           # Marked 渲染、代码块高亮与一键复制
    └── components/
        ├── status_bar.js         # 顶部状态栏与启动面板环境信息同步
        ├── chat_view.js          # 对话流渲染（用户指令条、思考节点、Markdown 流、行内终端通知）
        ├── tool_step.js          # 工具调用单行树状步骤节点（参数摘要、耗时统计与折叠输出）
        ├── slash_menu.js         # "/" 斜杠命令补全浮层
        ├── input_bar.js          # 底部居中命令行输入区（↑/↓ 历史、Tab/Enter 补全与忙碌锁定）
        └── settings_modal.js     # 服务配置模态框（内联校验提示）
```

## 常用修改速查

- **调整配色、圆角或对话宽度**：直接修改 `styles/tokens.css` 中的 `:root` 变量（如 `--bg-canvas`、`--content-max-width`）。
- **增删启动页快捷命令提示**：修改 `index.html` 中的 `#empty-state` 区块。
- **扩展后端推送事件**：在 `js/main.js` 的 `handleBackendEvent` 中新增对应 `case` 分支即可。
